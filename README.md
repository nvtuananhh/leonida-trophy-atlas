Leonida Trophy Atlas — the complete offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI, with cited guides, a six-stage platinum roadmap, missable flags, and a saved checklist.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Then serve the app with any static server, for example `python3 -m http.server 8080 --directory app`, and open http://localhost:8080 — it works with the network off.
