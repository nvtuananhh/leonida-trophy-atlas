Leonida Trophy Atlas is the complete offline GTA VI trophy guide and tracker for all 55 PlayStation 5 trophies, with cited guides, a six-stage platinum roadmap, missable flags, and a spoiler-safe checklist.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
python3 -m http.server 8080 --directory app
```
