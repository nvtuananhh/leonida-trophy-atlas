Leonida Trophy Atlas is the complete offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI, with cited guides, a platinum roadmap, missable flags and saved progress.

## Run it

```sh
python3 -m http.server 8080 --directory app
```

Then open http://localhost:8080 in desktop Chrome. The app works with the network off: it loads only its own files.
